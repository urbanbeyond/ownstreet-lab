# PROJECT AIDO — 화·목 urbanbeyond

> 의장 결정 2026-11-03 (R-027): OWN STREET 는 월·수·금, **화·목은 PROJECT AIDO** 가 urbanbeyond 계정을 채운다. AIDO 는 자동 발행하지 않는다 — AI 가 짜고 의장이 직접 올린다.
> 이 폴더는 공개 저장소다. 의장의 원본 마스터 문서 전체를 두지 않고, 발행에 필요한 기준만 옮겨 적는다 (출처: 의장의 `PROJECT_AIDO_MASTER_2026-11-03.md`).

## 1. AIDO 가 무엇인가
- 공식 이름 **PROJECT AIDO** · 대표 표기 **aido**(소문자) · 읽는 법 **에이아이두** · 보조 문구 **AI DO IT**(대문자)
- 부제: **인간과 AI의 공동 도전 프로젝트**
- 슬로건: **내가 상상하고, 우리가 만든다.**
- 핵심 질문: **"AI와 함께 도전하면, 실제로 어디까지 해낼 수 있을까?"**
- 원칙: **설명보다 실행. 성공뿐 아니라 실패도 콘텐츠다.** AI 는 기획과 제안에 참여하고, 실행과 최종 판단은 사람이 한다.
- 첫 번째 도전(AIDO 001): **"AI와 함께 인플루언서가 될 수 있을까?"** — AI 와 운영 전략을 세우고, 실제로 만들고 올리고, 조회수·구독자·반응과 실패까지 공개한다.
- 회차 구조: 사람이 질문 → AI 가 방법을 제안 → 사람이 실행 → 결과 검증 → 다음 실험
- 핵심 채널은 YouTube(Shorts·롱폼). urbanbeyond 계정의 화·목 글은 그 실험 기록과 핵심 장면을 나누는 자리다.
- OWN STREET·AGI ART 와의 관계: 모두 urbanbeyond 아래의 프로젝트. AIDO 는 AI 실험·실행을 공개하는 미디어이고, OWN STREET 의 과정을 소재로 다룰 수는 있지만 같은 프로젝트가 아니다. 다른 프로젝트의 글을 같은 문장·화면으로 다시 올리지 않는다.

## 2. 쓰는 기준 (지킨다)
- urbanbeyond 공식 계정의 말투: **수평어(평어)** — 반말 어미, 하대·위계 호칭 없이 (R-024).
- **확인된 것만 쓴다.** 채널 주소·핸들, 업로드 실적, 조회수·구독자 수, 수익은 기록이 생기기 전에는 쓰지 않는다. "30일 구독자 100명" 은 아직 확정 목표가 아니다.
- 마스터 문서의 **[제안]·[미확정]** 은 확정처럼 쓰지 않는다 (예: 시리즈명 CHALLENGE/LAB/LOG, `@aido_it`, 마스코트 이름).
- "AI 가 다 해 준다" 는 말 대신, 사람의 목적·판단·실행을 보여 준다. 실패는 숨기지 않는다.
- 외부 음악·영상·이미지는 권리를 확인한 것만 쓴다. 화면 녹화에서 개인정보·로그인 정보는 가린다.

## 3. 시각 기준
- 워드마크 `aido`(크게, 소문자) + `AI DO IT` + 한글 슬로건.

- 공식 로고·마스코트 가이드는 아직 승인 전. 승인되면 이 문서에 적는다.

- AIDO 의 구조는 **AI 가 짜고, 사람(의장)이 실행한다.** 그래서 화·목 글은 Claude 예약 작업으로 자동 등록하지 않는다 (의장 2026-11-03: "예약을 하지 않아도 되어 그건 chat gpt에서 알아서 할거라서", "자동 등록은 못해 왜냐하면 ai가 짜면 내가 실행하는 구조라서").
- 기획·대본은 ChatGPT 쪽에서 하고, 촬영·업로드·게시는 의장이 직접 한다.
- 이 저장소의 OWN STREET 자동 작업(새벽 사이클·Metricool 발행)은 화·목에 돌지 않는다. `aido/` 는 AI 팀 사이클이 건드리지 않는다.
