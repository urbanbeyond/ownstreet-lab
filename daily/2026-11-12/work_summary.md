- 구성: 상단에 제목("나의 자호(自號) 짓기")과 선언문 한 줄, 가운데 3칸 카드(①②③), 하단에 작은 안내 문구. ②번 칸 아래에 **힌트 단어장** 점선 박스 자리를 비워 뒀다 — 신 브랜더가 2026-11-15에 치환 사전에서 15~20개를 추려 채울 예정이라 지금은 내용을 넣지 않았다.
- 디자인 시스템(오프화이트 `#F6F3ED`, 거의 검정 `#13161B`, 시그널 오렌지 `#F85003`, Anton 제목, 2px 테두리 + 4px 하드 오프셋 그림자)을 그대로 적용했다. 다만 `app/styles.css`를 import 하지 않고 같은 값을 이 파일 안에 복제했다 — 이 워크북은 인쇄용 단독 파일이라, 인터넷 연결이 없거나 이 저장소 밖으로 파일만 옮겨도 그대로 열리고 인쇄되게 하기 위해서다.
- 레이아웃은 `210mm × 297mm` 고정 크기와 `@media print { @page { size: A4; margin: 0 } }`로 잡았다. 화면에서 미리 볼 수 있게 종이 바깥은 회색 배경, 종이 자체는 테두리+그림자가 있는 카드로 보이게 했다(인쇄 시엔 그림자·바깥 배경이 사라지고 종이만 남음).
- **Anton 폰트 인쇄 라이선스 재확인**(2026-11-10 회의에서 신 브랜더가 developer에게 물었고, developer가 "OFL일 것"이라 추정 답변하며 디자이너의 재확인을 부탁한 건): `scripts/fonts/OFL.txt` 원문을 직접 읽었다. SIL Open Font License 1.1이 맞고, 전문(PREAMBLE)에 "The requirement for fonts to remain under this license does not apply to any document created using the fonts or their derivatives"라고 명시돼 있다 — 즉 Anton으로 **만든 문서**(이 워크북 인쇄물 포함)는 라이선스 조건의 적용 대상이 아니라 자유롭게 인쇄·배포할 수 있다. 다만 "글꼴 파일 자체"를 재배포할 때는 조건 2번(라이선스 문구 동봉)이 적용되므로, Google Fonts CDN 대신 로컬 `scripts/fonts/Anton-Regular.ttf`를 `@font-face`로 그대로 가져다 썼고 `OFL.txt`도 저장소에 이미 함께 있다.
- Python Playwright(Chromium)로 직접 렌더링해 확인했다 — 화면 미리보기 스크린샷과 `emulate_media('print')` 인쇄 모드 스크린샷을 모두 떠서 3칸이 겹치거나 넘치지 않는지 봤고, `page.pdf()`로 실제 PDF를 뽑아 페이지 수가 정확히 1장(A4)인지 확인했다.
- 대표 이미지 `daily/2026-11-12/workbook_preview.png` (인쇄 모드 스크린샷)를 오늘의 시안으로 남겼다.

## 잘 안 된 것, 아쉬운 것
- Node.js용 Playwright가 이 환경엔 설치돼 있지 않아(캐시만 있고 `node_modules`에 없음) 처음엔 자바스크립트로 확인하려다 막혔다. Python 쪽엔 playwright가 설치돼 있어 그걸로 전환해 확인을 끝냈다 — 결과적으로 막히진 않았지만, 확인 경로가 평소(JS Playwright)와 달랐다는 점은 기록해 둔다.
- 실제 프린터로 뽑아보진 못했다(환경상 당연히 불가능). PDF 페이지 수와 화면 렌더링으로 간접 확인한 것이 한계다. 1기 모임 전에 누군가 실물로 한 번 뽑아 보고 여백·글자 크기가 실제로 괜찮은지 눈으로 봐 주면 좋겠다.
- "힌트 단어장" 박스 크기를 신 브랜더가 11-15에 채울 15~20개 단어 분량에 맞췄는지는 추측이다 — 단어 수가 생각보다 많으면 박스가 좁을 수 있다. 그땐 신 브랜더가 작업하면서 폰트 크기를 줄이거나 나에게 다시 알려주면 좋겠다.
