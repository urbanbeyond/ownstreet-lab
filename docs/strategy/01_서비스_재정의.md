# 01. 서비스 재정의 (초안) — 나다움을 찾는 티키타카

> 작성: 2026-11-17, 의장 결정(R-031)을 받아 운영(Claude)이 기획 초안으로 정리. **의장 확정 전 초안이다.**
> 앞 문서: `00_시장성_분석.md` (자기 것을 끝까지 해낼 때 가치가 생긴다 / AI가 다 해 주면 "내 것"이 아니다)

## 의장의 결정 (원문 요지, 2026-11-17 23:43)
- 티셔츠 만드는 것은 다 버린다. **'나답게' 살아가기 위해 티키타카 하는 서비스.**
- 나를 알아가고, 정말 나다운 게 뭔지 톡을 나누다 보면 알게 되는 서비스.
- 로그인은 구글로 동일하게. 대화는 **본인의 ChatGPT / Gemini / Claude** 로, **본인이 가진 사용량**을 쓴다.
- 자아인식에 관한 정보가 모여 있고, 사용자가 말을 하면 **상담가처럼 질문을 던져 스스로 알아가게** 한다.
- 이유: 네이밍·이미지·티셔츠 같은 생산적 창작은 사실 어렵지 않았다. **가장 어려운 건 진짜 자기를 제대로 인식하는 것.** 하나로 말하라고 하면 우선순위조차 못 정한다. 그래서 네이밍 이전에 자아인식으로 자기를 명확히 알고 정의하는 게 먼저다.

## 1. 문제 정의
사람들은 "나다운 것"을 **하나로 말하지 못한다.** 좋아하는 것·중요한 것이 여러 개 떠오르지만 순서를 정하지 못하고, 그래서 이름도, 옷도, 선택도 남의 기준을 빌린다.

## 2. 서비스 한 줄
**내 AI와 질문을 주고받으며, 빈칸 하나를 채우는 서비스.**

> # 나는 [          ]

(의장 결정 2026-11-18: "나는 [ ] 라고 심플하게")
- 끝에 남는 것은 **이 한 줄뿐**이다. 빈칸에는 사용자 자신의 말이 들어간다. 형식("___ 하는 사람이다")도 강요하지 않는다.
- 후보 모으기 → 셋 고르기 → 하나 남기기는 **대화 안에서** 일어나는 과정이지, 결과물의 칸이 아니다.
- 저장·공유되는 것도 이 한 줄. 화면도 이 한 줄에서 시작해 이 한 줄로 끝난다.
- 이 한 줄이 나중에 이름(호)·옷·브랜드로 이어질 수 있지만, **지금은 거기까지 만들지 않는다.**

## 3. "본인 AI로 대화" — 확인한 사실과 그에 맞춘 구조

**[사실] 우리 사이트 안에서 사용자의 ChatGPT·Gemini·Claude 구독 사용량을 끌어다 대화시키는 방식은 지금 일반 서비스에 열려 있지 않다.** (2026-10~11 확인)
- ChatGPT: "Sign in with ChatGPT" 가 있지만 OpenAI 가 정한 **제휴 앱**(주로 개발 도구)만 쓸 수 있다.
- Claude: Anthropic 은 다른 회사 앱이 Claude 로그인을 붙이는 것을 **허용하지 않는다.**
- Gemini: 구독 계정을 다른 도구에서 쓰는 것을 막고 있고, 계정 정지 사례도 있다. 다른 앱은 별도 유료 API 키가 필요.
- 사용자에게 API 키를 받는 방식은 구독과 별개로 돈이 나가고, 일반인은 키가 없다 → 쓰지 않는다.

**[구조] 그래서 방향을 뒤집는다: 대화는 사용자의 AI 앱 안에서 하고, 우리는 "질문 설계"와 "기록"을 맡는다.**

```
ownstreet (구글 로그인)                사용자의 AI 앱 (본인 사용량)
 ① "시작 대화문" 복사  ───────────▶  ChatGPT / Gemini / Claude 에 붙여넣고 대화
 ③ "나는 [ ]" 한 줄 저장  ◀───────  ② 대화 끝에 AI가 "나는 [ ]" 한 줄로 마무리
 ④ 내 한 줄 다시 보기·고치기
```
- **시작 대화문**: 우리의 핵심 자산. 질문하는 방법·순서·금지사항·안전선·끝내는 형식이 다 들어 있다. 세 AI 어디에 붙여도 같은 방식으로 움직이게 쓴다.
- **대화 내용은 우리 서버에 오지 않는다.** 사용자가 저장하기로 고른 한 줄만 온다. (개인정보 부담이 가장 작은 구조)
- 유료 API 를 붙이지 않는다 (팀 절대 규칙과도 맞음).
- 편의 입구는 나중에 (1차 범위 아님):
  - Gemini: 공유 Gem 링크 (단, 링크를 가진 사람은 지침을 볼 수 있다)
  - Claude: Claude 로 만든 공유 앱 — 쓰는 사람의 Claude 사용량으로 돈다
  - ChatGPT: 개인 계정은 GPT 를 새로 만들 수 없게 바뀜 → 복사 붙여넣기가 유일한 쉬운 입구

## 4. 대화의 원칙 (시작 대화문에 들어갈 것)
1. **AI 는 거울이다.** 판단·진단·조언·성격 유형 분류를 하지 않는다. 질문하고, 사용자의 말을 그대로 돌려준다.
2. **한 번에 질문 하나.** 짧게.
3. **고르게 한다.** "둘 중 하나만 남긴다면?" — 우선순위를 못 정하는 문제를 정면으로 다룬다.
4. **사용자의 단어를 쓴다.** AI 가 더 멋진 말로 바꾸지 않는다 (소유감 — `00` 문서 근거).
5. **끝이 있다.** 20~30분 안에 "나는 [ ]" 빈칸을 채우자고 제안한다. 빈칸은 사용자가 직접 채운다 — AI 는 후보를 대신 써 주지 않는다. 끝까지 해낸 경험이 핵심.
6. **안전선.** 상담·치료가 아니라 자기탐색 대화임을 처음에 밝힌다. 자해·자살 같은 위기 신호가 나오면 탐색을 멈추고 도움받을 곳(자살예방 상담전화 **109** 등)을 안내한다. "상담"이라는 말 대신 **"자기탐색 대화"**로 부른다.

> **덧붙이기 경계:** "자아인식 정보가 다 모여 있는" 백과사전을 만들지 않는다. MBTI·에니어그램·가치관 검사 등을 모으기 시작하면 다시 커진다. **질문 방법 하나**로 시작해, 사람이 실제로 막히는 곳만 고친다.

## 5. 버리는 것 / 남기는 것
| 버린다 (의장 결정) | 남긴다 |
|---|---|
| 티셔츠 주문 흐름, 목업, 사이즈·결제 안내 | 구글 로그인(Firebase), 디자인 시스템, LAB/LIVE 구조 |

| 네이밍 엔진을 1차 범위에 넣는 것 | 자호 워크북·네이밍 규칙 → "나는 [ ]" **다음 단계 후보**로 보관 |

## 6. 첫 검증 — 사람 손으로 먼저
- 기능을 만들기 전에, **시작 대화문 초안 하나**로 실제 사람이 끝까지 가는지 본다.
- 어디서 막히는지(특히 "셋 중 하나" 단계), 빈칸을 채운 뒤 어떤 표정인지 기록한다.
- 그다음에 사이트(복사 → 저장)를 만든다. 순서를 거꾸로 하지 않는다.
