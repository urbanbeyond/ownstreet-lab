# 02. 내가브랜드 — 원천 기획 (OWN STREET · 카카오 챗봇 공통)

> 작성: 2026-11-20, 의장 결정(R-034)을 받아 운영(Claude)이 정리.
> 앞 문서: `00_시장성_분석.md` → `01_서비스_재정의.md`("나는 [ ]"). **01 의 본질은 그대로 두고, 현장에서 확인한 것으로 방법을 바꾼다.**

## 의장의 결정 (원문 요지, 2026-11-20)
- "내가브랜드" 컨셉. 역할은 **네이밍과 이미지 생성까지**. 티셔츠는 이어지지 않는다(반응을 보고 나중에).
- 원천 기획은 하나. **OWN STREET 은 자체 설계 서비스**, **카카오 챗봇은 카카오 정책에 맞춰 커스텀하는 서비스.**
- 원데이클래스 현장에서 본 것:
  - "진짜 본인을 인식하는 것"은 **생각하는 게 가장 어렵다.** 그런데 **그냥 생각해 보라고 하면 더 어려워한다.**
  - **단서를 주고, "내가 어떻게 했는지" 보여 주고**, 완전 창작이 아니라 **따라 해 보거나 아이디어의 단초를 던져 주는 활동**이 필요하다.
  - **네이밍까지 가는 과정도 친절한 안내**가 필요하다.
  - 티셔츠 만들기는 더더욱 다음 영역이다.
- 내가브랜드는 **가볍게 즐길 수 있는 콘텐츠로 더 대중적으로 다가가기 위한 전략.** 본질은 바뀌지 않았고, 더 가볍고 친화적으로 진화한 것.

## 1. 무엇이 바뀌고 무엇이 그대로인가
| 그대로 (본질) | 바뀜 (방법) |
|---|---|
| 자기를 아는 것이 먼저다 | "생각해 보세요" → **단서를 주고 고르게 한다** |
| 마지막 선택은 사용자 | AI 는 거울(질문만) → **친절한 안내자: 예시·단초·후보를 준다. 고르고 고치는 건 사용자** |
| "나는 [ ]" 한 줄 | 끝이 아니라 **중간 정거장** — 그다음 네이밍·이미지로 이어진다 |
| 본인 AI 사용, 유료 API 없음 | (이미지 비용은 의장 결정 대기 — 7장) |
| — | 무거운 "자기탐색" → **가벼운 놀이 "내가브랜드"** |

> 2026-11-18 규칙 "AI 가 빈칸을 대신 채우지 않는다"는 이 문서로 바뀐다: **AI 는 후보를 줄 수 있다. 단, 사용자의 단서에서 나온 후보여야 하고, 최종 한 줄과 이름은 사용자가 고르고 고친다.**

## 2. 흐름 — 다섯 걸음, 걸음마다 단서와 예시
```
① 단서 고르기 → ② 나는 [ ] → ③ 이름 짓기 → ④ 브랜드 이미지 → ⑤ "내가 만든 브랜드 어때?" 공유
```
| 걸음 | 사용자가 하는 일 | 우리가 주는 것 (단서·예시·따라 하기) |
|---|---|---|
| ① 보고 고르기 | **먼저 다른 사람의 여정을 보고**, 카드에서 **고른다** (쓰지 않아도 됨) | **시작점 돕기(R-035):** 시작하자마자 "무엇을 원해?"라고 묻지 않는다. 먼저 의장의 여정(만든 과정 → 결과물)과 다양한 사람의 예시를 짧게 보여 준다. 그다음 호 짓는 네 기준을 쉬운 카드로: **머무는 곳 · 하고 싶은 것 · 겪은 일 · 아끼는 것**. 각 카드에 보기 3~5개 + "직접 쓰기" |
| ② 나는 [ ] | 고른 단서로 빈칸을 **채운다** | 고른 단서로 만든 **문장 틀 2~3개**("나는 ○○에서 △△하는 사람") + **예시 사람**이 채운 한 줄 |
| ③ 이름 짓기 | 후보 중 **고르고 고친다** | 짓는 방법 3가지를 예시와 함께(내 단어 그대로 / 호처럼 두 글자 / 영어·소리 바꾸기). `docs/naming-rules.md` 의 "손님 단어 남기기" 규칙 |
| ④ 브랜드 이미지 | 분위기를 **고른다** | 이름+한 줄로 만든 **이미지 프롬프트**(스타일 보기 3개 중 선택) |
| ⑤ 공유 | 카드 한 장을 **자랑한다** | 브랜드 이름 + "나는 [ ]" + 이미지가 들어간 공유 카드 |

- **"내가 어떻게 했는지" 예시가 걸음마다 붙는다.** 한 사람이 다섯 걸음을 따라간 예시를 처음부터 끝까지 보여 준다.
- **예시는 하나가 아니라 여러 갈래.** 1기 현장(11-19, 7명 전원 완성)에서 중간중간 다양한 예시를 보여 준 것이 생각 정리에 도움이 됐다 → 걸음마다 서로 다른 예시 2~3개.
- **걸음 수는 늘리지 않는다.** 시작점 돕기는 새 걸음이 아니라 ① 안에 넣는다.
- 한 걸음은 1~3분. 전체 10분 안팎. 가볍게 끝까지 가는 것이 목표 (`00` 문서: 끝까지 해낼 때 가치가 생긴다).

## 5. 말투
가볍고 친근하게, 수평어(공식 계정 규칙과 같음). 정답을 가르치지 않는다 — "이렇게 해 본 사람도 있어, 너는 어때?"

## 6. 하지 않는 것 (덧붙이기 경계)
- 티셔츠·굿즈 주문 (반응을 보고 나중에)
- 성격 유형 검사, 점수, 진단
- 걸음 늘리기 — 다섯 걸음을 넘기지 않는다
- 회원 커뮤니티·피드 — 공유는 카드 한 장으로 밖(카톡·인스타)에 나간다

## 7. 의장이 정할 것
1. **④ 이미지 생성 비용**: (가) 사용자 본인 ChatGPT·Gemini 에서 만들게 한다 — 우리가 이미지 프롬프트만 주고 비용 0원 / (나) 우리가 직접 생성 — 유료 API, 장당 비용 발생 / (다) 처음엔 (가), 반응 보고 (나)
2. **"내가 어떻게 했는지" 예시 인물**: 1기 현장에서 의장 본인의 과정·결과물·여정 공유가 효과가 있었다(R-035) → **의장 본인 예시를 기본으로 제안**. 실제 내용(과정·결과물)은 의장이 직접 준 것만 쓴다 — 받기 전까지는 자리만 비워 둔다. 다양한 예시용 나머지는 가상 인물(가상임을 표시). 확정 대기.
3. **카카오 챗봇과의 순서**: 웹을 먼저 만들고 챗봇이 따라갈지, 동시에 갈지
