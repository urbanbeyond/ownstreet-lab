# 따라 하기 예시 — 의장 (실제 답)

> 서비스 첫 화면 "내가 어떻게 했는지" 예시. **의장이 2026-11-20 23:11 에 직접 답한 내용만** 적는다 (R-035·R-036). 공개 저장소·서비스에 그대로 보인다.
> ②·③ 의 후보는 운영이 의장의 단어로만 만든 것이고, **고르는 건 의장** — 고르기 전까지 "선택 대기".

## ① 의장의 답
| 질문 | 의장의 답 |
|---|---|
| 오늘을 색 하나로 말하면? | 하늘색 |
| 하루 중에 제일 좋아하는 시간은? | 잠들기 전 |
| 요즘 제일 많이 쓰는 이모지는? | 스마일(웃는) |
| 오늘 먹은 것 중에 제일 기억나는 건? | 족발덮밥 |
| 어릴 때 질리지도 않고 했던 놀이는? | 간지럼 태우기 |
| 친구들이 너한테 자주 하는 말은? | 다정하다 |
| 최근에 "오, 이거 좋다" 하고 저장해 둔 건? | 고양이 이야기 |
| 주말에 아무 계획 없으면 제일 먼저 하는 건? | 전시회 보러 가기 |

## 첫 시험 결과 (2026-11-20 23:16)
②·③·④ 후보를 보여 주자 의장 답: **"다 별로야"**. 운영이 본 원인과 고칠 점:
1. 사소한 답 여러 개를 **단어 그대로 이어 붙였다** → 카드 문구 같고 "나" 가 없다.
2. **하나 남기기(⑥)를 건너뛰고** 후보를 만들었다 → 중심이 없다.
3. 사소한 답은 단서일 뿐, 뜻은 그다음에 있다 → **"그거 뭐가 좋았어?" 한 번 더 묻기**가 빠졌다.
4. 이름이 단어 조합(다하·TICKLE)이라 이야기가 없다.
→ 흐름 수정: 사소한 질문 → 하나 고르기 → **한 번 더: 뭐가 좋았어?(보기 있음)** → 그 답으로 나는 [ ]. 아래 후보들은 실패 기록으로 남긴다.

## ② 나는 [ ] — 첫 후보 (❌ 의장: 다 별로)
- 나는 다정하게 웃게 만드는 사람 (다정하다 · 스마일 · 간지럼 태우기)
- 나는 잠들기 전, 하늘색처럼 고요해지는 사람 (잠들기 전 · 하늘색)
- 나는 주말이면 전시를 보며 이야기를 모으는 사람 (전시회 · 고양이 이야기)

## ③ 이름 — 첫 후보 (❌ 의장: 다 별로)
- 내 단어 그대로: 하늘색 · 잠들기전 · 스마일
- 호처럼 두 글자: 다하(다정+하늘) · 하담(하늘+잠들기 전의 '담담')
- 소리·영어 바꾸기: SKY SMILE · BEFORE SLEEP · TICKLE

## ④ 이미지 방향 — 첫 예시 (❌ 의장: 다 별로)
하늘색 바탕, 웃는 얼굴의 고양이, 전시 포스터 같은 여백.
