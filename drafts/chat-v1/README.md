# 대화형 주문 초안 (chat-v1)

팀이 출범하기 전에 의장이 먼저 만들어 둔 초안이다. `app/` 의 한 페이지 버전(v0)과 달리,
채팅창에서 시스템이 순서대로 묻고 손님이 답하는 방식으로 주문을 받는다.

- 들어 있는 것: `index.html`, `app.js`, `styles.css` (화면 쪽만)
- 들어 있지 않은 것: `config.js`, 서버 코드. 설정값과 서버는 이 폴더에 두지 않는다.
- 묻는 순서: 이미지 링크 → 사이즈 → 이름 → 전화번호 → 주소 → 요청사항 → 확인 → 로그인 → 접수
- 서버가 사이즈·주소·요청사항을 받을 수 있어야 한다 (서버 쪽 변경과 배포가 필요하다).
- 검증 상태: 모의 환경에서만 확인했다. LAB 에도 LIVE 에도 아직 올라가지 않았다.

이 초안을 그대로 쓸지, 고쳐 쓸지, 버릴지는 팀 회의에서 정한다.
